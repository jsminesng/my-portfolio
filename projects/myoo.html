MYOO – AI-powered Mood Journaling Mobile App

An AI-powered mobile journaling application that helps users record emotions, reflect on daily experiences, and receive contextual emotional support through conversational AI.

Watch Demo View PPT

Overview

MYOO is a cross-platform mood journaling app that helps users track emotions, write diary entries, and reflect through AI-assisted conversation. The product combines personal journaling with contextual emotional support powered by an LLM.

Users can go through onboarding, log moods, upload media, manage profiles, and chat with an assistant that responds based on journal context.

Tech Stack

React Native Expo TypeScript Supabase Gemini API

  • Media uploads for diary entries

  • Secure backend with Supabase Auth and RLS

My Contributions

  • Built a cross-platform mobile app with React Native, Expo, TypeScript, and Supabase for journaling and AI reflection.
  • Designed application architecture and workflows for onboarding, emotion tracking, diary creation, and profile management.
  • Integrated Gemini API for context-aware emotional support chat based on journal entries.
  • Implemented secure backend architecture with Supabase Auth, PostgreSQL, Storage, and RLS.

Challenges

  • Designing journaling and chat flows that feel personal without making the product feel intrusive.
  • Passing useful journal context into LLM conversations while keeping the experience simple.
  • Structuring mobile workflows and backend security for sensitive personal content.

What I Learned

  • How to structure a React Native + Expo app around clear user journeys.
  • Practical patterns for combining journaling data with LLM-powered conversational support.
  • How Auth, Storage, and RLS help protect private user content in a mobile product.
