Respondy – AI-powered Chat Assistant

An AI-powered desktop application that analyzes chat screenshots and provides context-aware reply suggestions using Google Gemini.

Watch Demo View PPT

Overview

Respondy is a desktop chat assistant that turns chat screenshots into context-aware reply suggestions. Users upload screenshots, review AI-generated responses, and keep conversation history for faster follow-ups.

The product focuses on making everyday messaging workflows faster by combining screenshot analysis with Gemini-powered response generation in a desktop Electron app.

Tech Stack

Electron Next.js React JWT REST API Google Gemini

  • User uploads a chat screenshot from the desktop app.
  • Frontend sends the image to backend services via REST API.
  • The backend analyzes the screenshot and generates reply suggestions with Gemini.
  • Suggested replies and conversation history are shown in the UI.

Key Features

  • Screenshot upload and analysis
  • Context-aware reply suggestions
  • Conversation history
  • Desktop Electron experience
  • REST API integration with AI backend

My Contributions

  • Developed the desktop frontend using Electron, Next.js, and React.
  • Built interfaces for screenshot upload, AI-generated reply suggestions, and conversation history.
  • Integrated REST APIs for screenshot analysis and AI-generated responses.
  • Designed responsive and intuitive UI for a smoother desktop experience.

Challenges

  • Turning screenshot-based chat context into useful reply suggestions without making the UI feel complicated.
  • Connecting Electron frontend flows with backend APIs for analysis and response generation.
  • Designing conversation history and suggestion UI that stays easy to scan on desktop.

What I Learned

  • How Electron + Next.js + React can work together for a desktop AI product.
  • Practical patterns for screenshot-driven workflows and REST API integration.
  • How to shape AI response UX so suggestions feel actionable instead of noisy.
